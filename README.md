# وصيتي مكتوبة — Wasiyyati (Flutter v0.3.2)

تطبيق Flutter باللغة العربية لتوثيق **مسودة شخصية** للوصية، وتنظيم الديون والحقوق والأمانات والممتلكات. لا يلغي الحاجة لمراجعة مختص شرعي وقانوني ولا يُعد محررًا رسميًا للوصية.

## إصلاح v0.3.2 — بناء Android عبر أقراص Windows مختلفة

- يعالج تعارض Kotlin incremental cache عند وجود الحزم على قرص والمشروع على قرص آخر.
- يقوم السكربت scripts/repair-android-kotlin.ps1 بإضافة kotlin.incremental=false إلى android/gradle.properties محليًا.
- يتم استدعاؤه تلقائيًا في setup.ps1 وbuild-release.ps1. يمكن تشغيله يدويًا بعد git pull دون إعادة إنشاء Android.
- بعد فشل بناء سابق، شغّل سكربت الإصلاح ثم flutter clean وflutter pub get وأعد البناء.
- تعطيل Kotlin incremental compilation قد يجعل البناء التالي أبطأ، لكنه لا يغيّر بيانات الخزنة.

## الجديد في v0.3.0 — حماية النسخ واستعادتها

- **قفل اختياري للتطبيق** باستخدام مصادقة الجهاز (البصمة أو رمز الجهاز). يطلب التحقق بعد العودة من الخلفية؛ لا يستبدل تشفير الملفات الموجود.
- **نسخة احتياطية قابلة للنقل** بامتداد `.wbackup`، باستخدام AES-256-GCM ومفتاح مشتق من كلمة مرور مستقلة بواسطة PBKDF2-HMAC-SHA256 بعدد 310,000 دورة وملح عشوائي.
- **استيراد آمن:** التحقق من كلمة المرور وسلامة النسخة قبل عرض تأكيد صريح لاستبدال محتويات الخزنة الحالية. لا توجد عملية دمج تلقائية.
- **لا تغيير على بيانات الخزنة** (`schema: 1`) أو المفتاح المحلي القديم. لا توجد مزامنة تلقائية ولا إرسال لخادم.
- **لا ترفع كلمات المرور إلى GitHub** ولا تسجلها في الملفات النصية. فقدان كلمة مرور النسخة يعني تعذر استعادتها.
- إعداد Android مطلوب عند أول تشغيل لهذه النسخة: يُجري `scripts/setup.ps1` تحديثات MainActivity/AndroidManifest والـLaunchTheme اللازمة لمصادقة الجهاز. السكربت لا يحذف مجلد Android ولا بيانات التطبيق.
- اختبارات للنسخة المحمولة: نجاح النقل، اختلاف الأملاح، وكلمة المرور الخاطئة، وكشف العبث، والإصدارات غير المدعومة.

> هام: الإصدار 0.3.0 لا يمثل ضمانًا قانونيًا أو أمنًا مثاليًا. جرّب تصدير نسخة واستعادتها ببيانات تجريبية قبل الاعتماد عليه، واحتفظ بنسخة أخرى موثقة من المستندات المهمة. أي ملف PDF يتم تصديره غير مشفر.

### الحفظ والأمان

بيانات المستخدم تحفظ محليًا باستخدام AES-256-GCM بمفتاح موجود في التخزين الآمن للنظام. **لم يتغير التنسيق المشفر في هذه النسخة** (`schema: 1`). لا يوجد اتصال خادمي ولا تسجيل دخول. أي ملف PDF تصدره **غير مشفر**.

> تنبيه: أصبحت ميزة قفل الشاشة والنسخ الاحتياطي المشفر متاحة اختياريًا في الإصدار 0.3.0. لا تعتمد على النسخة التجريبية بوصفها النسخة الوحيدة لوثائق مهمة. ضياع الهاتف أو حذف التطبيق أو فقدان مفتاح التشفير قد يجعل المعلومات غير قابلة للاستعادة. لا تحفظ كلمات مرور أو رموز تحقق في السجلات.

## التشغيل على Windows 10/Flutter

فك الضغط إلى `D:\Dev\Projects\wasiyyati` بحيث تجد الملف `pubspec.yaml` مباشرة داخل ذلك المجلد.

```powershell
cd D:\Dev\Projects\wasiyyati
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
flutter run
```

ينفذ السكربت `flutter create . --platforms=android` لإنشاء ملفات Android الأصلية، ويمنع النسخ التلقائي لبيانات التطبيق، ويضبط minSdk إلى 24، ثم يشغّل `flutter pub get` و`flutter analyze` و`flutter test`، ويتوقف عند أي خطأ.

إن اكتملت الاختبارات، يمكنك إخراج APK:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-release.ps1
```

المسار المتوقع: `build\app\outputs\flutter-apk\app-release.apk`.

**التحقق:** جرى فحص بنية الملفات واختبارات النماذج نصيًا في بيئة الإعداد، لكن لم ينفذ Flutter analyze أو Flutter test أو بناء Android هنا لأن Flutter SDK غير موجود في البيئة. شغّل سكربت الإعداد على جهازك وأرسل أي أخطاء كي نعالجها.

## الحدود الوظيفية

- ما زالت المرفقات الفعلية للمستندات غير متاحة؛ الخزنة تدير الوصية والحقوق، مع التصدير والنسخ الاحتياطي.
- لا يوجد توثيق عبر جهة رسمية أو احتساب أنصبة الورثة.
- أرقام المبالغ ليس لها حقل عملة مستقل في الإصدار الحالي، لذلك لا نحسب مجاميع عبر العملات.
- قد يتطلب PDF اتصالاً بالإنترنت لأول مرة لتنزيل خط Cairo من Google Fonts، لكن لا ترسل بيانات الوصية لخدمة الخط.
- خطوط واجهة Flutter تتبع خطوط النظام للحفاظ على التشغيل دون إنترنت؛ قد تختلف قليلًا عن نسخة Figma التي تستخدم Amiri وCairo.

## عند ظهور No supported devices connected

هذا يعني أن Flutter لا يرى هاتف Android أو محاكيًا يعمل. ظهور Chrome وWindows كـ«غير مدعومين» أمر طبيعي لأن المشروع يجهز منصة Android فقط.

```powershell
flutter doctor -v
flutter emulators
flutter devices
```

شغّل محاكيًا موجودًا من Android Studio > Device Manager، أو من الطرفية باستخدام معرّفه الظاهر في `flutter emulators`:

```powershell
flutter emulators --launch YOUR_EMULATOR_ID
flutter devices
flutter run
```

أو وصّل هاتف Android بعد تفعيل خيارات المطور وتصحيح أخطاء USB والموافقة على اتصال الكمبيوتر. لا تحتاج جهازًا متصلًا لإنشاء APK: `flutter build apk --release`.

إذا كنت تحدّث مجلد مشروع موجودًا، فك ضغط التحديث في **مجلد الأب** `E:\Android`، حتى تستبدل الملفات تحت `E:\Android\wasiyyati` دون حذف مجلد `android` المولّد على جهازك. لا تحذف المشروع الموجود إذا كان يحتوي ملفات أو إعدادات محلية أضفتها بنفسك.
